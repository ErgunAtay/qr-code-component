### What I learned

While building this project, I worked on centering a card on the page, styling accessible hover and focus states, and building a responsive layout with a mobile-first approach.

```css
.link:hover,
.link:focus {
  background-color: hsl(var(--clr-green));
  color: hsl(var(--clr-dark-grey));
}
```

I also learned how using CSS custom properties to manage the color palette from one place makes the project easier to read and maintain.

### Continued development

- Try different layout approaches with CSS Grid
- Practice more with accessibility (a11y): focus-visible, ARIA labels
- Make animations and transitions smoother
